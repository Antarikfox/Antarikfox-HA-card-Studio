# Antarikfox Glass 4.0.1 для Home Assistant

**by Antarikfox · [antarikfox.ru](https://antarikfox.ru)**

Тема и карточка-обёртка «светящееся стекло». В версии 3: 49 спецэффектов, 10 динамических событий, шрифт и размер на всю тему, исправление узких карточек и заголовков, новогодний режим с гирляндой, шарами, снежной шапкой и сосульками. Интерфейс на русском и английском (по языку профиля HA).

## Установка

1. `themes/antarikfox_glass.yaml` → `/config/themes/`, в `configuration.yaml`: `frontend: themes: !include_dir_merge_named themes`, затем `frontend.reload_themes`.
2. `www/antarikfox-glass-card.js` → `/config/www/`.
3. Ресурс `/local/antarikfox-glass-card.js?v=4.0.1`, тип **«JavaScript-модуль»**.
4. Для исправления заголовков и кантов на обычных карточках нужен **card-mod** (HACS).

Конфигурации v1 и v2 работают без изменений.

### Новое в конструкторе
- **Условия показа** у любого предмета (👁 «Показывать, когда»): состояние, «кроме состояния», больше/меньше, время `18:00-07:00`. Поддерживается и формат `visibility:` из HA (`condition: state | numeric_state | screen | and | or`).

## Что нового в 3.2

### Конструктор карточек
В редакторе первым разделом идёт **«Конструктор карточки»**. Карточка собирается из предметов и сама управляет устройствами, вложенная карточка не нужна.

| Предмет | Что делает |
|---|---|
| `title` | Заголовок с иконкой и состоянием |
| `image` | Фото; `state_images` меняет фото по состоянию с плавной сменой, `use_entity_picture` берёт картинку сущности |
| `entity` | Иконка, название, состояние и переключатель |
| `value` | Крупное число с единицей |
| `button` / `buttons` | Кнопка или ряд кнопок со стилями заливка, контур или круглая |
| `slider` | Ползунок, сам выбирающий сервис: яркость, громкость, положение штор, скорость вентилятора, температура, number |
| `progress` | Шкала по значению |
| `media` | Обложка, трек и управление плеером |
| `chips` | Компактные состояния нескольких сущностей |
| `text` | Текст с подстановками `{state:…}`, `{name:…}`, `{attr:сущность:атрибут}`, `{unit:…}` |
| `row` / `column` | Группы предметов (вложенные) |
| `divider` / `spacer` | Разделитель и отступ |
| `card` | Любая карточка HA внутри конструктора |

Действия — родные действия HA: `tap_action` и `hold_action` с `toggle`, `more-info`, `navigate`, `url`, `perform-action` (с `data`), `none`. Значение `auto` означает переключение для переключаемых устройств и окно сущности для остальных.

В редакторе есть палитра предметов, быстрые макеты (Свет, Телевизор, Климат, Музыка, Датчик, Кнопки сцен), перемещение, дублирование и удаление, вложенные ряды. Выбор сущностей, действий, цветов и фото по состояниям сделан родными элементами.

```yaml
type: custom:antarikfox-glass-card
preset: cyber
entity: media_player.bedroom_tv
content:
  padding: 14
  gap: 10
  blocks:
    - type: image
      entity: media_player.bedroom_tv
      state_images:
        "on": /local/tv_on.png
        "off": /local/tv_off.png
      height: 150
      fit: contain
      tap_action: { action: toggle }
    - type: row
      blocks:
        - { type: title, entity: media_player.bedroom_tv, size: s }
        - { type: button, entity: media_player.bedroom_tv, icon: mdi:power, style: round, tap_action: { action: toggle } }
    - { type: slider, entity: media_player.bedroom_tv }
```

### Импорт: обернуть или пересобрать, фото сохраняются
- **Обернуть как есть:** старая карточка внутри стекла. Удаляются только сплошной фон, рамки и тени. **Фоны-фотографии (`background-image: url(…)`), в том числе внутри `state:`, остаются**, поэтому по нажатию фото меняются как раньше.
- **Пересобрать в конструкторе:** карточка раскладывается на предметы.
  - **Фото:** основное, `state_image`, `state[].entity_picture` и `state[].styles…background-image` становятся предметом «Фото» с переключением по состояниям.
  - **Действия:** `tap_action` и `hold_action` переносятся.
  - **Стеки:** превращаются в ряды и колонки.
  - **Шаблоны:** карточки с шаблонами (`{{ }}`, `[[[ ]]]`) остаются вставкой, чтобы логика не сломалась.
- В отчёте видно, сколько найдено фото и по каким состояниям они меняются.

### Заголовки без окантовки
Кроме известных заголовков (heading, mushroom title/chips, bubble), без стекла и рамки теперь показывается любая низкая карточка без иконок, кнопок, переключателей и картинок: markdown-заголовки, «Добро пожаловать» и т. п. Карточки с иконкой (button-card, плитки) остаются стеклом, у них только уменьшается скругление.

### Копирование
По http (HA в локальной сети) браузер запрещает обычный буфер обмена, поэтому копирование теперь работает и через запасной способ. В конфигураторе две кнопки: «Скопировать» и «Способ 2». В редакторе после импорта есть «Скопировать YAML».

## Что нового в 3.1

### Тёмный текст на тёмном — исправлено
Варианты темы (Cyber, Ember, Ice, Matrix, New Year, Dark) были описаны без `modes:`. Home Assistant считал их светлыми и для новых элементов 2025 года подставлял светлые значения: тёмный текст плашек, карточек зон и заголовков, белое поле выбора темы в профиле. Теперь у всех тёмных вариантов есть `modes: dark`. Кроме того, контрастные цвета явно заданы для `ha-color-text-*`, `mdc-text-field-*`, `mdc-select-*`, заголовков и списков. После обновления файла темы выполните `frontend.reload_themes` и обновите страницу.

### Рамки на узких заголовках — исправлено без card-mod
Карточка Antarikfox, подключённая как ресурс, сама находит на панели обычные карточки HA, пока активна тема Antarikfox:
- **Заголовки** (`heading`, mushroom title/chips, bubble): без стекла, рамки и тени, с мягким свечением текста.
- **Низкие карточки:** скругление не больше трети высоты.

При смене темы на чужую всё возвращается как было. Отключить можно в теме: `afx-theme-autofix: "off"`.

### Блик в цвет карточки
Блик больше не серый: его верхний угол берёт цвет верх-лево, полоса — середины, а нижний отсвет — низ-право. Сила окраски задаётся в карточке `glare_tint: 0…1` (по умолчанию 0.45), в теме — `afx-theme-glare-tint: "45%"`.

### Импорт старой карточки
В редакторе и конфигураторе есть кнопка **«📥 Импорт карточки»**. Вставьте YAML или JSON любой карточки (button-card, mushroom, tile, стеки, picture-elements…), и она станет содержимым стекла:
- **Сущность:** находится главная, по ней подбираются эффекты (свет — цвет от лампы и вспышка при включении; медиа — ритм и эквалайзер; охрана — тревога с молнией; дверь — звонок при открытии…).
- **Цвета:** берутся из карточки, в первую очередь из теней и свечений, и становятся тремя цветами свечения.
- **Шрифт:** берётся из `font-family`.
- **Старые стили:** фон, рамки, скругления и тени удаляются, так как с ними стекло выглядит грязно. Остальные стили и шаблоны не трогаются.

Анализ работает с конфигурацией (YAML). Картинки, нарисованные внутри HTML/JS-карточки, программа не «понимает»: такую карточку можно обернуть в стекло, но переработать её рисунок можно только вручную.

### Узкие поля и заголовки (исправлено)
Карточки-заголовки (`heading`, mushroom title, bubble, chips) и стеки больше не получают стеклянный фон и рамку: им по задумке HA не положены отступы, поэтому текст упирался в скругление. Низкие карточки (tile, button, entity, mushroom) получают меньшее скругление `afx-theme-radius-compact`. Карточка Antarikfox сама уменьшает скругление, если она низкая (`radius_auto`, включено по умолчанию). Нужен card-mod: он добавляет картам классы `type-…`.

### Шрифт и размер для всей темы
В теме есть блок «Типографика»:
```yaml
afx-theme-font: "Manrope"                     # любой Google-шрифт, карточка подгрузит его сама
ha-font-family-body: "Manrope, Roboto, sans-serif"
ha-font-family-heading: "Manrope, Roboto, sans-serif"
primary-font-family: "Manrope, Roboto, sans-serif"
paper-font-common-base_-_font-family: "Manrope, Roboto, sans-serif"
mdc-typography-font-family: "Manrope, Roboto, sans-serif"
ha-font-size-scale: "1.1"                     # масштаб всех шрифтов (HA 2025.5+)
```
Без интернета положите шрифт в `/config/www/fonts/` с CSS-файлом `@font-face` и укажите `afx-theme-font-url: "/local/fonts/manrope.css"`. Шрифт подгружается, когда открыта панель с ресурсом Antarikfox.

Для отдельной карточки: `font`, `font_scale`, `content_scale`, `content_padding`, `text_color`, `legibility: soft | strong`.

- Учитываются системные «уменьшить движение» и «уменьшить прозрачность».

# Справочник v2

## Редактор

Редактор целиком собственный: выпадающие списки с поиском и превью, палитра, переключатели и выбор сущностей. Управление с клавиатуры: стрелки, Enter, Esc.

**Палитра** включает:
- спектр насыщенности и яркости с ползунком оттенка;
- ввод HEX и пипетку с экрана (в Chrome и Edge);
- 20 цветов-«предметов» в виде самоцветов: лава, янтарь, изумруд, ледник, сапфир, аметист, неоновая вывеска, ртуть, лунный свет и другие;
- недавние цвета;
- кнопку «Из пресета», которая возвращает цвет пресета.

**Гармония из средней** строит три цвета свечения из среднего: аналоговую схему, триаду, комплементарную, раздельную, монохромную или тетраду.

На верхней панели есть кнопки **«Удиви меня»** (случайный гармоничный вид), **«Копировать стиль» / «Вставить стиль»** (перенос оформления между карточками без сущностей) и **«Сбросить вид»**. Двойной щелчок по подписи ползунка сбрасывает его к значению по умолчанию.

## Текстуры

- **CSS-текстуры (14):** noise, frost, carbon, hex, grid, dots, scanlines, brushed, diamond, circuit, waves, lowpoly, topo, weave.
- **Живые (4):** `plexus` (сеть узлов, как в референсе), `synapse` (сеть с бегущими импульсами), `shards` (мерцающие кристаллы), `constellation` (созвездия). Их окрашивает свечение карточки: они ярче у краёв, а цвет каждой точки берётся из градиента «верх-лево → середина → низ-право». Сила зависит от `glow_intensity` и приглушения.
- **`texture_lit: true`** заставляет любую CSS-текстуру светиться цветами канта и разгораться к краям.

## Примеры

Дождь, сила которого зависит от датчика осадков:
```yaml
type: custom:antarikfox-glass-card
preset: ocean
fx: [rain, fog]
fx_entity: sensor.precipitation
fx_min: 0
fx_max: 10
card: { type: weather-forecast, entity: weather.home }
```

Искры от нагрузки и сетка-синапсы:
```yaml
type: custom:antarikfox-glass-card
preset: matrix
texture: synapse
fx: [sparks]
fx_entity: sensor.house_power
fx_max: 5
card: { type: sensor, entity: sensor.house_power, graph: line }
```

Батарея как светящийся кант-прогресс:
```yaml
type: custom:antarikfox-glass-card
preset: toxic
progress_entity: sensor.phone_battery
card: { type: tile, entity: sensor.phone_battery }
```

Цвет от температуры (холод → комфорт → жара):
```yaml
value_colors:
  entity: sensor.outdoor_temperature
  min: -20
  max: 35
  colors: ["#60a5fa", "#4ade80", "#fb923c", "#ef4444"]
```

Колонка пульсирует в такт и светит лучами только во время игры:
```yaml
entity: media_player.living_room
beat: true
beat_bpm: 120
fx: [rays, bokeh]
fx_when: active
```

Тревога: красное стекло, молнии и глитч:
```yaml
alert:
  entity: binary_sensor.leak
  state: "on"
  color: "#ff2d55"
  fx: [lightning, glitch]
```
