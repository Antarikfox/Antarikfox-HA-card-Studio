# Contributing

Open an issue before large changes. Keep `custom:antarikfox-glass-card` compatible.
Check JavaScript with `node --check dist/antarikfox-glass-card.js` and run
`python3 scripts/check_package.py`. Verify Studio, card editor, sandbox and real
entity controls in a development Home Assistant instance before a release.
Do not include tokens, real entity exports or private images in pull requests.
